## 2. Model Parameters & Generation Settings

Every generated image in [`images/`](./images) was produced via the Gemini Interactions API (`POST https://generativelanguage.googleapis.com/v1beta/interactions`) using `gemini-api image --body @- --out "images/<model>.jpg"`.

### Common Multimodal Input Configuration
- **`input[0]` (Reference Image):**
  - `type`: `"image"`
  - `mime_type`: `"image/jpeg"`
  - `data`: Base64-encoded bytes of [`Screenshot 2026-10-01 at 2.19.42 AM.jpeg`](./Screenshot%202026-10-01%20at%202.19.42%E2%80%AFAM.jpeg) (`404,256` bytes raw / `539,008` chars base64)
- **`input[1]` (Prompt):**
  - `type`: `"text"`
  - `text`: Full markdown content of [`prompt-image01.md`](./prompt-image01.md) (`6,266` bytes)
- **Top-Level Request Parameters:**
  - `stream`: `false`
  - `response_format`: `{"type": "image"}`
  - `generation_config`: `{"image_config": {"aspect_ratio": "9:16"}}`

## 3. Exact Interactions API Request Payload

Below is the exact JSON body structure constructed by [`run-image-models-test.sh`](./run-image-models-test.sh) and piped into `gemini-api image --body @- --out "images/<MODEL_NAME>.jpg"`:

```json
{
  "model": "<MODEL_NAME>",
  "stream": false,
  "response_format": {
    "type": "image"
  },
  "generation_config": {
    "image_config": {
      "aspect_ratio": "9:16"
    }
  },
  "input": [
    {
      "type": "image",
      "mime_type": "image/jpeg",
      "data": "<BASE64_ENCODED_REFERENCE_IMAGE>"
    },
    {
      "type": "text",
      "text": "<MARKDOWN_PROMPT_TEXT>"
    }
  ]
}
```
